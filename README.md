Superstore Sales Analysis

Project Overview

This is a beginner-level data analysis project using Microsoft Excel to analyze Superstore sales and profit.

Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard

Analysis Performed

- Region-wise Sales Analysis
- Category-wise Sales Analysis
- Category-wise Profit Analysis

Key Performance Indicators (KPIs)

- Total Sales: 2,297,200.86
- Total Profit: 286,397
- Total Quantity: 37,873

Conclusion

This project helped me understand sales and profit performance using Excel Pivot Tables, Charts, and Dashboard.
